# Prove-am Mobile App

A separate Capacitor wrapper for the existing Prove-am web app.

The production app is not modified. The native shell loads:
https://prove-am.onrender.com

## Build

Use Node.js 22+, then run npm install in this directory.
Run npx cap add android for Android and npx cap add ios on macOS for iOS.
Run npx cap sync, then open the generated native project in Android Studio or Xcode.
